## Enterprise AI Document

This sample document is intended for testing Azure AI Document Intelligence, Pinecone, and Retrieval-Augmented Generation (RAG). It contains headings, multiple paragraphs, a table, and an embedded image.

## Introduction

Artificial Intelligence enables machines to perform tasks that normally require human intelligence. Modern enterprise solutions combine vector databases, embeddings, and large language models.

A Retrieval-Augmented Generation system stores document embeddings in a vector database and retrieves relevant chunks before generating an answer.

Azure OpenAI provides embedding models and chat models that integrate well with Azure AI services.
